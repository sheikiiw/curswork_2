# Vacancy Parser

Проект для получения, обработки и хранения вакансий с hh.ru с использованием API.

## Установка
1. Склонируйте репозиторий: `git clone <URL>`
2. Установите зависимости: `pip install -r requirements.txt`
3. Запустите программу: `python src/main.py`

## Функциональность
- Поиск вакансий по ключевому слову через API hh.ru.
- Фильтрация вакансий по ключевым словам и диапазону зарплат.
- Сохранение и удаление вакансий в JSON-файл.
- Вывод топ-N вакансий по зарплате.

## Требования
- Python 3.8+
- Библиотека `requests`

## Тестирование
Запустите тесты: `python -m unittest discover src/tests`
